## Computer

Students are expected to bring a laptop computer to class. The programme assumes access to a Unix-like working environment. Typical options include:

- Linux
- macOS with Terminal or equivalent
- Windows with the Windows Subsystem for Linux

## Practical expectation

The courses assume that students can work comfortably in a command-line environment and use common scientific computing tools. Several core courses also assume or encourage programming in Python.
